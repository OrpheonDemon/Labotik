# Laboratorio Frontend

Este es el directorio para la aplicación frontend de nuestro laboratorio.

## Tecnologías Sugeridas
Dependiendo de la complejidad y los requisitos del proyecto, podemos estructurar este frontend de las siguientes maneras:

1. **Vite + React (Recomendado para SPA moderno)**: Un entorno ultra rápido y moderno para construir la interfaz.
2. **Next.js (Recomendado para SSR / SEO)**: Ideal si necesitamos renderizado en el servidor o rutas dinámicas complejas.
3. **HTML5, Vanilla CSS & JS**: Ideal para un prototipo rápido y ligero sin dependencias complejas.

## Integración con el Backend
El backend está construido con **FastAPI** y se ejecuta en `http://localhost:8000`. Podemos usar `fetch` o `axios` para conectarnos a las APIs.
